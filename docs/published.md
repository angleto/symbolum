# The published documents

**EXCERPT — for anyone scanning the index:**
Every proof document this repository publishes, with what it imports and the statement of every
definition and theorem it holds. These are proofs written in the proof language
([language.md](language.md)) rather than in Scala, checked by the kernel on every run of the suite.
The listing below the marker is generated by
`tools/sbt "published/runMain garden.xeno.symbolum.published.Published"` and pinned by
`PublishedSpec`, so a document added and not listed here fails the build and names that command.

*If you modify this file and this excerpt no longer accurately describes its content, you must
update it.*

## What a published document is

A document under `modules/published/src/main/resources/garden/xeno/symbolum/published/` that is
named in `Published.Names`. Publishing it means three things:

- it is checked on every run of the suite, and a declaration that does not check, or an import that
  does not resolve, fails the build;
- its theorems are a library, `Published.standard.library`, beside the chain's
  ([lemmas.md](lemmas.md)), each labelled with the document that holds it;
- any document can `import` it by name, wherever that document is, and cite its theorems.

The published documents are made again in **one** theory, so two of them cannot define one name or
declare one theorem, even when neither imports the other, and that theory holds exactly the axioms
of the chain. `Published` in `modules/published` says what it refuses and why.

## Reading the listing

Statements are printed as the library's are: by the theory's printer, which names a bound variable
by its type. A theorem written `!n:num. ?k:num. ...` in its document can print as
`!n:num. ?m:num. ...`, which is the same statement. A definition is listed under the constant's own
name, and its statement is the defining equation, which is the fact `rewrite NAME` unfolds.

## Doubling

Imports nothing.

```
  DOUBLE                   DOUBLE = (\n:num. n + n)
  DOUBLE_ADD               !n:num. !m:num. DOUBLE (n + m) = DOUBLE n + DOUBLE m
  DOUBLE_SUC               !n:num. DOUBLE (SUC n) = SUC (SUC (DOUBLE n))
  DOUBLE_ZERO              DOUBLE 0 = 0
```

## Parity

Imports `Doubling`.

```
  EVEN_OR_ODD              !n:num. ?m:num. n = DOUBLE m \/ n = SUC (DOUBLE m)
```
