## A proof language checked by the kernel

`docs/adr/0070` is the decision and `docs/language.md` is the reference. A file of this shape, which is the first example of that reference and is checked by
`LanguageSpec` with the others:

```
theorem ADD_ZERO_LEFT : !n:num. 0 + n = n
proof
  fix n
  induction n
  case zero:
    by rewrite NUM_ADD_ZERO
  case succ m ih:
    calc 0 + SUC m = SUC (0 + m) by rewrite NUM_ADD_SUC
         _ = SUC m by rewrite ih
  end
qed
```

is checked with `tools/sbt "tactics/runMain garden.xeno.symbolum.tactics.Check FILE"`, or with
`--json` for a program reading the report. The reader and the elaborator are untrusted; what they
produce is a sequence of kernel inferences, and a declaration is reported proved only when the
kernel built its theorem.

What this release covers is increments 1 and 2 of that record:

- **Increment 1**, the language. `fix`, `assume`, `have`, `show`, `obtain`, case analysis,
  induction (over `num` by default, or by a named principle with `using`), `split`, `choose`,
  `witness`, `rewrite`, `apply` with labelled obligations, and `calc` chains, closed by `auto`,
  `ring`, `linarith`, `arith` over the naturals, `rewrite`, `exact` and `apply`, combined with
  `then` and `first`. Errors are recovered per declaration and per failed `have`, so one document
  reports every problem it has rather than the first.
- **Increment 2**, what a failure and a success say. A step that fails is put to `Refutation`, and
  its answer is reported with the kind `docs/adr/0005` keeps apart: a counterexample found by
  sampling or by solving, premises that cannot all hold, a decision that no counterexample exists,
  a sample that found none, a question never asked, or one sampling cannot settle. A theorem that
  checks is reported with its price: the axioms it rests on, the library facts it cites, the facts
  of the same document it used, and the number of inferences.

**What it does not do yet** is in `docs/language.md` under that heading: publishing a document's
theorems into the library, an editor protocol, the notebook as a surface for it, and a simplifier
and datatype declarations. Those are increments 3 to 6.

**Two changes below the language came with it.** `Parser.term` takes the types of the variables a
proof has already fixed, so a claim inside a proof reads its free variables at the types the proof
gave them. And `Refutation` now says a set of premises is contradictory when the solver decides it,
where it said a sample survived: on the line before this release, `{x < 0, 0 < x}` was reported as
surviving a hundred samples, and it is now reported contradictory.

**The coverage gate refused the first cut of this release, and the repair is tests.** Measured on
`77096477` in a worktree never built, `tactics` read 89.24% against its floor of 92.50. `Check`
now answers through `Check.run`, so its usage errors and exit status are asserted without starting
a process, and two specs pin every malformed construct of a document with its line and message,
the routes each method takes, and the report in both forms. The table found one defect, fixed in
the same commit: a method's malformed argument was reported under the keyword of the line holding
it, so `by exact` with nothing after it said "`by` wants the fact".

## The rest

- **One instance per term, held weakly** (`docs/adr/0069`). Each distinct term is constructed once,
  and the `fromProduct` of the mirror Scala 3 derives for a case class refuses, so a term exists
  only because a checking constructor built it. This is the kernel change counted above.
- **The licence is the AGPLv3** (`docs/adr/0068`), so a network service built on this code owes its
  source too. `CLAUDE.md` became `AGENTS.md` in the same window, and every live reference moved.
- **Peano arithmetic proves a true strict order between numerals**, and an existential from a
  closed instance; the universal side waits on the object logic, which `docs/adr/0040` records.
- **`Model.Reals` answers `inv 0 = 0`**, as the chain proves since `docs/adr/0053`; it moves no
  outcome of `Cost` and adds a witness point to claims already `Fails` at a computed zero (card
  354256d9).
- **E5 at phi = 1/10**, with `7/20 <= 9/16` as an instance of `BLACKWELL_GARBLING`.
- `ROADMAP.md`, the work ahead grouped by what it is for, and a pin in `CanonicalFormSpec` on the
  product case.

## Upgrading

The one change made to refuse something a caller could write before: a term built through the
derived `Mirror.ProductOf` of a term class, rather than through the kernel's factories, is refused,
which is the point of `docs/adr/0069`. Nothing else in this release was written to change what a
caller of `7.0.4` may write; that is the intent of the changes listed, not a measurement over
downstream code.
