# 7.0.3

**EXCERPT — for anyone scanning the index:**
The release in which a decision that had been recorded and not carried out was carried out: `+`,
`*`, `<` and `<=` now stand for the naturals' constants as well as the reals', which is
`docs/adr/0018`. It adds no mathematics and no module, and it re-spells 135 of the library's
statements, so it is a release a consumer has to read before upgrading rather than after. Cut on
2026-09-15 at `985b93c`, seventeen commits past `7.0.2`.

## The figures are frozen, and that is not the usual rule here

Every other figure in this repository is generated or pinned by a test, because a figure written by
hand goes stale. A figure in a release note cannot: it describes a tag, and a tag does not move. So
the numbers below are measurements of `985b93c` and are meant to stay exactly as they are. If one of
them disagrees with the repository tomorrow, the repository moved and this note did not, which is
what it is for.

Where a figure is also pinned somewhere, the pin is named, so a reader can see what would have had
to fail for the number to be wrong.

## What this release is

`docs/adr/0018` was accepted before `7.0.2` and nothing implemented it. That is the worst state a
decision can be in: it reads as settled and the code disagrees with it, and the disagreement is
invisible to everyone who has read the record. `7.0.3` is where it landed.

What it is **not** is new mathematics. Measured across the two tags:

## What a consumer has to change

This is the part to read before upgrading. Everything here is a change to what a caller may write,
not to what the system can prove.

**A constant's name is no longer a symbol, and three were.** `Real.Addition` was literally the
string `"+"`. It is now `real_add`, with `real_mul`, `real_lt` and `real_le` beside it, so that the
four read alike. Nothing a reader of a *statement* sees moves: the printer is keyed by constant and
asks the notation what to spell it with, so `x + y` still prints `x + y`. What moves is any code
that named the constant. `Real.Zero` is still `"0"` and `Real.One` still `"1"`, left alone
deliberately: they are `docs/adr/0012`'s problem and not this change's.

**A text whose type nothing determines is refused, and that now includes a text made only of
digits.** `0 < 1` at the widest signature is ambiguous in two ways at once and is refused naming
both; `(0:real) < 1` reads. The escape `Signature.term(text, expected)` does **not** rescue this
when the text is a proposition, because the type a caller can pass is then `bool`, and `bool` says
nothing about the operands. A caller whose ambiguity is inside an equation annotates in the text.

**An order a normal form depends on must not be a property of how two constants are spelled.**
`Arithmetic.ringOrder` needed the product to sort before the sum and was getting that from ASCII:
`*` precedes `+`, and `real_mul` does not precede `real_add`. The rename reversed the comparison and
associativity stopped flattening. One corpus entry in `PolynomialSpec` caught it and no other test
in the repository did. The ranking is written down in that file now, and the general form of the
lesson is in `CLAUDE.md`.

## What it buys

`!n:num. n + 0 = n` reads and is proved, where until this release it was refused with "real and num
cannot be the same type". `NUM_DIVISION_UNIQUE` is the one to look at. At `7.0.2`:

```
!x:num. !y:num. !z:num. !u:num. !v:num.
  NUM_ADD (NUM_MUL x y) z = NUM_ADD (NUM_MUL x u) v /\ NUM_LT z x /\ NUM_LT v x ==> y = u /\ z = v
```

At `7.0.3`:

```
!x:num. !y:num. !z:num. !u:num. !v:num.
  x * y + z = x * u + v /\ z < x /\ v < x ==> y = u /\ z = v
```

Which is the uniqueness of quotient and remainder as anybody would write it, and it is the same
theorem: nothing was reproved.

**135 statements move for `num`, and the figure carries its criterion because a second one is
available and disagrees.** 135 is `CLAUDE.md`'s, counted as statements that move *for `num`*. A
diff of the generated listing between the two tags counts **137** changed entry lines, because that
criterion also picks up definition bodies and the `le` to `real_le` rename, which are not `num`
moving. Both are right about what they count. Neither should be "corrected" into the other.

Overloaded only where the operation is the **same** one. `-` and `/` are truncated subtraction and
floor division over `num`, so they keep the prefix form, and a reader who writes them is told which
constant to reach for rather than given the wrong one quietly.

`docs/reading-register.md` gained more than `docs/lemmas.md` did, and those are the rows nobody has
read. That is a cost of this release rather than a benefit, and it is recorded here because nothing
else will say it.

## The showcase

`docs/theorems.md` is new: twelve results worth reading, each as a page carrying the statement in a
form set for reading and a form that parses, what it rests on, the derivation where one was
recorded, what it cost, and the command that gets it back. `docs/lemmas.md` remains the index; this
is the showcase, and the difference is the question each answers.

It shipped with a defect that was found and fixed inside the same release, and the shape is worth
keeping. Every page said "Put the claim to the prover, which settles it from the whole tactic
surface" and nothing had ever run one of the published commands. Six of the twelve are settled by
the surface and six are refused, because they were obtained by hand derivations. The sentence no
longer promises settlement, every page carries `Essay.RefusalNotice` saying that a refusal is the
obstacle the surface met rather than a verdict on the claim, and `ShowcaseSpec` now runs the
published claims instead of counting them.

## Guards that reported a completeness they did not have

Six of the seventeen commits are of one kind, and they are the reason this release is larger than
its mathematics. Each is a check that read as protection and protected less than it said:

- a census of the rewriter's callers that could not see eight calls sitting in the shared recording
  layer;
- a census against a hand-written list of modules that was one module short, and the module it
  missed is the one a person types at;
- a guard whose own comment counted its list twice and gave two different answers;
- two properties of the type-definition rule that `docs/adr/0006` stated in prose and no assertion
  executed, one of which is a soundness escape;
- the one surface that talks to a browser, which nothing could reach because its endpoints are
  private and only live behind a running server;
- the library of every proved lemma, reachable from nowhere.

Two of those were settled by writing the wrong implementation and running the suite: the assertion
that is supposed to catch it either fails or it does not, and in both cases exactly one assertion
failed and the rest stayed green.

## The gate

Full suite on a clean tree at the tagged commit:

```

```

**2135 tests, 0 failures**, at `985b93c`, with `HEAD` and the dirty count recorded before and after
the run and unchanged across it. That last part is not ceremony: on a shared checkout a full run is

produced three failure attributions of which none was sound.

about its own releases.
